## 🚀 快速开始

**方式一（推荐）：用 Python 启动本地服务器**

> 你正在学 Python，顺便认识一下：`http.server` 是 Python 标准库自带的简易网页服务器。

1. 打开终端（cmd / PowerShell），进入本目录；
2. 运行：
   ```
   python server.py
   ```
3. 浏览器会自动打开 `http://localhost:8000`。

**方式二：直接双击 `index.html`**

所有功能（除 AI 外）都能正常使用。个别浏览器可能拦截网页直接调用 AI 接口，此时请改用方式一。

> 建议使用 **Chrome 或 Edge** 浏览器（语音朗读、跟读评分、语音输入都需要它们支持，且语音识别需要联网）。

## 📱 手机和其他人怎么访问

### 方式一：同一 WiFi 下用手机访问（最快）

1. 电脑上运行 `python server.py`（新版会自动监听局域网）；
2. 手机连**和电脑同一个 WiFi**，用相机扫浏览器自动弹出的**二维码**，或在手机浏览器输入控制台里打印的「手机访问」地址（形如 `http://192.168.x.x:8000`）；
3. 打不开时：检查是否同一 WiFi（**校园网常隔离设备互访**，可改用手机开热点、电脑连热点）；Windows 防火墙弹窗点「允许访问」。

> ⚠️ 注意：局域网 http 地址下，**手机的麦克风功能（跟读评分/语音输入）用不了**，朗读、词卡、测验、AI 聊天等都正常；AI 需要在每台设备上各自填一次自己的 API Key；每台设备的学习数据是独立的。

### 方式二：部署到公网（其他人在任何地方都能访问）

推荐 **GitHub Pages**（免费、支持 HTTPS，手机上麦克风功能也能用，还能顺便学会 git）：

1. 注册 [github.com](https://github.com) 账号；
2. 新建仓库（New repository），名字如 `english-hub`，选 **Public**；
3. 点 **Add file → Upload files**，把本文件夹里的 `index.html`、`css`、`js` 整个拖进去提交（无需装 git）；
4. 仓库 **Settings → Pages → Source 选 main 分支 → Save**；
5. 等 1~2 分钟，网站地址就是 `https://你的用户名.github.io/english-hub/`，任何人、任何设备都能访问。

国内访问慢的替代：Gitee Pages（需实名）、Vercel / Netlify（免费，绑定 GitHub 一键导入）。

> 🔒 部署前注意：**不要把 API Key 写进代码上传**！Key 只存在每台设备自己的浏览器里（localStorage），访问者各自配置，互不共享费用。

## 🤖 开启 AI 陪练（1 分钟）

1. 打开 [platform.deepseek.com](https://platform.deepseek.com) 注册账号（手机号即可）；
2. 进入「充值」页充值（价格便宜，学生充 10 元可以用很久，新用户常有免费体验额度，以官网显示为准）；
3. 进入「API keys」页面，点「创建 API key」，复制 `sk-` 开头的密钥；
4. 回到网站 →「AI陪练」页 → 粘贴密钥 →「保存配置」→「测试连接」，成功即可开聊。

> ⚠️ **安全提示**：API Key 相当于你的钱包钥匙，只保存在你自己浏览器里，**不要**分享给任何人，也不要把它写进公开的代码/截图里。

## 🛠️ 想自己动手改？（前端 + Python 实践机会）

网站代码全部是中文注释，建议你按顺序玩：

1. **加单词**：打开 `js/data-vocab.js`，在对应分类的 `words` 数组里照格式加一条即可；
2. **加场景**：打开 `js/data-content.js`，在 `SCENARIOS` 里加一个场景；
3. **改样式**：`css/style.css` 顶部的 CSS 变量（颜色）随便改，立刻生效；
4. **加页面**：看懂 `index.html` 里每个 `section` 和 `js/app.js` 的 `showTab` 导航逻辑，就能新增一个模块；
5. **Python 进阶**：试着把 `server.py` 换成 Flask 版本，或写一个接口把你学过的单词存到 SQLite 里。

## ❓ 常见问题

- **跟读评分/语音输入没反应？** 需用 Chrome/Edge、允许麦克风权限、保持联网。
- **AI 请求失败？** 检查 Key 是否正确、是否有余额；双击打开网页时被拦截的话，改用 `python server.py`。
- **数据会丢吗？** 数据存在浏览器本地，清缓存/换浏览器会丢。定期在「计划」页点「导出全部数据」备份。
- **想加"电子"专业词汇、更多场景或听力音频？** 直接跟 AI 助手说，或按上面"自己动手改"的方式添加。
